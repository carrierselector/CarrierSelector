## CarrierSelector 6.3

**iPhone Duo.** Складной iPhone Duo (iPhone19,4, плата V68) добавлен в список поддерживаемых моделей. Профили сверены с его собственной прошивкой iOS 27.2.1 (24B91034): все 685 профилей операторов совпадают байт в байт с теми, что встроены в программу, — вместе с подписями Apple и настройками под плату V68. Программа и каталог профилей по сравнению с 6.2 не менялись.

Архивы собраны на GitHub Actions из этого репозитория; для каждого есть подтверждение сборки (`gh attestation verify <архив> --repo carrierselector/CarrierSelector`).

Что было в 6.2: пункт 3 возвращает профиль, встроенный в iOS (пакет с пустым `SupportedSIMs`); прежний возврат — пункт 7; справка APN и MMS для Беларуси.

| Архив | Для чего |
|---|---|
| macOS Apple Silicon | Mac на M1 и новее |
| macOS Intel | Mac на Intel |
| Windows x64 | нужен Apple Devices или iTunes |
| Linux x64 | нужен usbmuxd |

Python в сборках уже есть. Контрольные суммы — в `CarrierSelector-v6.3-SHA256.txt`.

Сборки включают pymobiledevice3 (GPL-3.0-or-later) и профили операторов Apple, права на которые принадлежат Apple Inc.
