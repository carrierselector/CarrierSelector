## CarrierSelector 6.5

- Добавлена поддержка iOS 26 (26.6–26.7). На телефонах с iOS 26 программа предлагает версии профилей 70.0 и находит точный исходный профиль для отката.
- Ufone_pk убран из рекомендуемых: на Билайне с ним не проходят входящие звонки. Для Билайна рекомендуются Ncell_np, MobiCom_mn, MTN_cy, Vodafone_hu.
- Добавлено предупреждение при выборе профиля, с которым на Билайне не проходят входящие звонки.
- Убраны лишние отметки о непроверенных версиях: в списке остаются только рекомендуемые варианты с понятными описаниями.

| Архив | Для чего |
|---|---|
| macOS Apple Silicon | Mac на M1 и новее |
| macOS Intel | Mac на Intel |
| Windows x64 | нужен Apple Devices или iTunes |
| Linux x64 | нужен usbmuxd |

Python в сборках уже есть. Контрольные суммы — в `CarrierSelector-v6.5-SHA256.txt`.

Сборки включают pymobiledevice3 (GPL-3.0-or-later) и профили операторов Apple, права на которые принадлежат Apple Inc.
